# Solara Cleaning Services

A polished, responsive marketing website for a residential cleaning company. The design uses a warm coastal palette, expressive editorial typography, layered photography, and clear conversion paths inspired by the visual character of the provided reference site while establishing an original brand identity.

## Key Features

- Responsive single-page layout with mobile navigation
- Recurring, deep-clean, and move-in/move-out service sections
- Company story, process, testimonial, FAQ, and final call-to-action sections
- Accessible interactions and reduced-motion support
- Working quote request form powered by Netlify Forms
- Local image assets for dependable production rendering
- SEO title and description metadata

## Technology

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Vite 7
- Tailwind CSS 4 tooling with custom global CSS
- Lucide React icons
- Netlify Forms and Netlify deployment adapter

## Local Development

Install dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

The Vite development server runs on port `3000`. For Netlify platform emulation, use:

```bash
netlify dev --port 8889
```

## Before Launch

Replace the placeholder company name, phone number, email address, service area, and testimonials with final business information. Form submissions appear in the site's Netlify Forms dashboard after deployment.
